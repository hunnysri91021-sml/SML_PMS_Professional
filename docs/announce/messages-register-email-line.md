## อีเมล
หัวข้อ: [HR] ลงทะเบียนอีเมลและ LINE เพื่อรับ PIN เข้าระบบ SML PMS
เรียน พนักงานทุกท่าน
1. ลงทะเบียนอีเมลที่หน้าเข้าสู่ระบบ (ลิงก์ด้านล่าง) ด้วยรหัสพนักงานและอีเมลบริษัท
2. เพิ่มเพื่อน LINE OA ของบริษัท และพิมพ์รหัสพนักงานส่งในแชท 1 ครั้ง
3. ฝ่าย HR จะตรวจสอบและส่ง PIN ไปยังอีเมลที่ท่านลงทะเบียน
ลิงก์: https://hunnysri91021-sml.github.io/SML_PMS_Professional/SML_PMS_v14.html
ขอบคุณครับ/ค่ะ ฝ่ายทรัพยากรบุคคล

## ขั้นตอนของ HR (หลังพนักงานลงทะเบียน)
1. เข้าระบบด้วย Admin → หน้าผังองค์กร & พนักงาน
2. ตรวจรายชื่อว่าอีเมลที่ลงเป็นของตัวพนักงานจริง
3. กด "📧 ส่ง PIN ให้ผู้ลงทะเบียนอีเมล" → ตรวจรายชื่อใน confirm → ยืนยัน
   (ระบบสุ่ม PIN 4 หลักส่งทางอีเมล ตั้ง PIN เฉพาะคนที่ส่งอีเมลสำเร็จ)
4. ตรวจช่อง LINE User ID ในหน้าแก้ไขพนักงานว่าผูกแล้ว (หรือดูว่าพนักงานได้ข้อความยืนยันใน LINE)

## ข้อควรระวัง
- ลงทะเบียนอีเมลได้เฉพาะคนที่ยังไม่มี PIN และยังไม่มีอีเมลในระบบ; ลงผิดต้องให้ HR แก้
- ถ้าตั้ง REGISTER_EMAIL_DOMAINS ใน Worker จะรับเฉพาะอีเมลโดเมนบริษัท
- LINE: รหัสที่ผูกกับคนอื่นแล้วจะถูกปฏิเสธ (ติดต่อ HR)
- Worker ต้อง redeploy เวอร์ชันล่าสุด และตั้ง LINE_CHANNEL_SECRET/ACCESS_TOKEN + Webhook แล้ว
